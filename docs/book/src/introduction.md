# はじめに

## この本は何か

これは `ui-forge` の**コードを読む前に読む本**です。[ADR-0001](https://github.com/dOtOb9/ui-forge/blob/main/TaskSheets/ADR-0001-design.md)
やタスクシートの書き写しではありません。

このリポジトリには、判断の経緯を記録した `TaskSheets/ADR-0001` と、作業記録である
`TaskSheets/F1`〜のタスクシートがすでにあります。**なぜその設計になったか**を
知りたいときは、今もそれらが一次資料です。この本は、そこへ行く前に**全体像をつかみ、
どのファイルから読めばいいかを示す地図**です。

## 読み方

各章は次の3つを短く書きます。

- **このコードは何をしていて、なぜそうなっているか**
- **経緯**（ADR へのリンク。詳しい判断の理由はそちらにあります）
- **節ごとのソースファイルへのリンク**。GitHub 上のファイルを直接開けます

各章の最後に「**まず読むファイル**」を1〜3個挙げます。迷ったらそこから読んでください。

## 正確さについて

この本の内容は、ADR やタスクシートではなく**実際のコード**を確認して書いています。
両者が食い違っている箇所は、**コードの通りに**書き、食い違いがあることを本文に
明記しています。

画面や実機で確認されていないことは「未確認」と明記します。本の内容を鵜呑みにせず、
疑わしい箇所はリンク先のソースファイルを実際に開いて確認してください。

## リンクについて

本文中のソースへのリンクは `https://github.com/dOtOb9/ui-forge/blob/main/<パス>` の
形にしています。この本を書いている時点ではこの名前の GitHub リポジトリはまだ
存在しませんが、所有者がこの名前でリポジトリを作る前提でリンクを張っています。

## この本が対象にするコード

この本は、`ui-forge` を作ったブランチが分岐した時点の `main`（コミット `86b62a3`）の
コードを対象にしています。これと並行して、プラットフォーム対応（P1: Windows / Android /
Web）が別の作業で進行中です。**ファイルを開く・読む・変更を検知する部分
（`src/preview/host/`、`src-tauri/src/watch.rs`）は、この本では扱いません。**
P1 が合流したあと、別の作業で「[プラットフォーム](./platforms.md)」の章を書きます。

## 手元で開く

標準の mdBook だけでビルドできます（拡張は使っていません）。

```bash
cargo install mdbook   # 入っていなければ
mdbook serve docs/book
```

ブラウザで `http://localhost:3000` を開くと、保存するたびに再読み込みされます。
一度だけビルドしたい場合は `mdbook build docs/book`（`docs/book/book` に出力されます）。
